# План реализации Telegram Poster Bot

## Этап 1 — Скелет проекта и инфраструктура

**Цель:** Настроить проект, зависимости, конфигурацию и базу данных.

**Задачи:**
- [ ] Создать структуру директорий (`bot/`, `bot/db/`, `bot/handlers/`, `bot/keyboards/`, `bot/states/`, `bot/middlewares/`)
- [ ] Создать `requirements.txt` (aiogram>=3.4, aiosqlite, python-dotenv)
- [ ] Создать `.env.example` с описанием переменных окружения
- [ ] Реализовать `bot/config.py` — загрузка конфигурации из env
- [ ] Реализовать `bot/db/database.py` — подключение к SQLite, создание таблиц (миграции)
- [ ] Реализовать `bot/db/queries.py` — базовые CRUD-функции для users, channels, posts, publications
- [ ] Реализовать `bot/middlewares/db.py` — middleware для инъекции db-сессии в хендлеры
- [ ] Создать `bot/__main__.py` — точка входа: инициализация бота, подключение роутеров
- [ ] Создать `Procfile` и `railway.toml` для деплоя

**Результат:** Бот запускается, подключается к БД, отвечает на /start.

---

## Этап 2 — Команда /start и главное меню

**Цель:** Реализовать стартовый экран и навигацию.

**Задачи:**
- [ ] Реализовать хендлер `/start` — регистрация пользователя в БД, вывод главного меню
- [ ] Создать Reply-клавиатуру главного меню:
  - 📝 Создать пост
  - 📢 Мои каналы
  - 📋 Мои посты
- [ ] Реализовать `bot/keyboards/menus.py` — функции для генерации клавиатур

**Результат:** Пользователь видит меню и может нажимать на кнопки (хендлеры пока заглушки).

---

## Этап 3 — Управление каналами

**Цель:** Подключение и удаление каналов.

**Задачи:**
- [ ] Реализовать хендлер «📢 Мои каналы» — показать список каналов пользователя
- [ ] Реализовать добавление канала:
  - Пользователь пересылает сообщение из канала или отправляет @username/ID канала
  - Бот проверяет, что он является администратором этого канала (через `bot.get_chat` + `bot.get_chat_member`)
  - Бот сохраняет канал в БД
- [ ] Реализовать удаление канала — inline-кнопка «Удалить» рядом с каждым каналом
- [ ] Обработка ошибок: бот не админ, канал не найден, канал уже добавлен

**Результат:** Пользователь может добавлять и удалять каналы. Бот проверяет свои права.

---

## Этап 4 — Создание поста (текст + кнопки)

**Цель:** Реализовать FSM для создания поста с текстом и inline-кнопками.

**Задачи:**
- [ ] Определить FSM-состояния в `bot/states/post.py`
- [ ] Реализовать хендлер «📝 Создать пост»:
  - Состояние `waiting_for_text` — бот просит ввести текст поста
  - Пользователь вводит текст (поддержка HTML-форматирования Telegram)
- [ ] Реализовать добавление кнопок:
  - Состояние `waiting_for_buttons` — бот предлагает добавить кнопки или пропустить
  - Парсинг формата: `Текст - URL` (каждая строка = кнопка, `---` = новый ряд)
  - Валидация URL
- [ ] Сохранение поста в БД

**Результат:** Пользователь может создать пост с текстом и кнопками. Пост сохраняется в БД.

---

## Этап 5 — Предпросмотр и публикация

**Цель:** Показать превью поста и опубликовать в выбранный канал.

**Задачи:**
- [ ] Реализовать предпросмотр поста:
  - Состояние `preview` — бот отправляет пользователю пост в том же виде, как он будет в канале (текст + inline-кнопки)
  - Под превью — кнопки: «✅ Опубликовать», «✏️ Редактировать текст», «🔘 Изменить кнопки», «❌ Отмена»
- [ ] Реализовать выбор канала:
  - Состояние `select_channel` — показать список каналов пользователя inline-кнопками
  - При нажатии — бот публикует пост в канал через `bot.send_message(channel_id, ...)`
- [ ] Сохранение информации о публикации в таблицу `publications`
- [ ] Обработка ошибок: нет прав, канал удалён, и т.д.

**Результат:** Полный цикл — создание поста → превью → публикация в канал.

---

## Этап 6 — Список постов и повторная публикация

**Цель:** Просмотр ранее созданных постов и возможность повторной публикации.

**Задачи:**
- [ ] Реализовать хендлер «📋 Мои посты» — список постов пользователя с пагинацией
- [ ] Для каждого поста показывать:
  - Превью текста (первые 50 символов)
  - Дата создания
  - Кнопки: «👁 Просмотр», «📢 Опубликовать», «🗑 Удалить»
- [ ] Реализовать повторную публикацию существующего поста
- [ ] Реализовать удаление поста

**Результат:** Пользователь видит свои посты, может пересмотреть, опубликовать повторно или удалить.

---

---

## Порядок реализации

```
Этап 1 → Этап 2 → Этап 3 → Этап 4 → Этап 5 → Этап 6 → Этап 7
  ↓         ↓         ↓         ↓         ↓         ↓         ↓
Скелет   Меню    Каналы    Посты    Превью    Список   Деплой
```

Каждый этап — отдельный коммит. После каждого этапа бот должен быть в рабочем состоянии.
