# Telegram Poster Bot — Концепция проекта

## Назначение

Телеграм-бот для создания и публикации постов в Telegram-каналы. Каждый пользователь бота управляет своими каналами и постами независимо от других.

## Основной сценарий использования

1. **Подключение канала** — пользователь добавляет бота в свой Telegram-канал как администратора с правами на публикацию. Затем через бота регистрирует канал в системе.
2. **Создание поста** — пользователь создаёт пост: вводит текст, опционально добавляет inline-кнопки (текст + URL).
3. **Предпросмотр** — бот показывает превью поста с кнопками. Пользователь подтверждает или редактирует.
4. **Публикация** — пользователь выбирает канал из списка своих каналов и публикует пост.

## Ключевые требования

- **Мультипользовательность** — у каждого пользователя свои каналы и посты, данные изолированы.
- **Inline-кнопки** — поддержка URL-кнопок под постом (несколько рядов, несколько кнопок в ряду).
- **Предпросмотр** — обязательный предпросмотр перед публикацией.
- **Хранение постов** — созданные посты сохраняются и могут быть опубликованы повторно.
- **MVP** — минимально жизнеспособный продукт, без отложенных постов и медиафайлов на первом этапе.

## Модель данных

### Таблица `users`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PK | Telegram user ID |
| username | TEXT | Username (опционально) |
| created_at | TIMESTAMP | Дата регистрации |

### Таблица `channels`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PK AUTOINCREMENT | Внутренний ID |
| user_id | INTEGER FK | Владелец (ссылка на users) |
| channel_id | INTEGER | Telegram channel ID |
| channel_title | TEXT | Название канала |
| channel_username | TEXT | Username канала (опционально) |
| added_at | TIMESTAMP | Дата добавления |

### Таблица `posts`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PK AUTOINCREMENT | Внутренний ID |
| user_id | INTEGER FK | Автор (ссылка на users) |
| text | TEXT | Текст поста (HTML) |
| buttons | TEXT (JSON) | Кнопки в формате JSON |
| created_at | TIMESTAMP | Дата создания |

### Таблица `publications`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PK AUTOINCREMENT | Внутренний ID |
| post_id | INTEGER FK | Ссылка на пост |
| channel_id | INTEGER FK | Ссылка на канал |
| published_at | TIMESTAMP | Дата публикации |
| message_id | INTEGER | ID сообщения в канале |

## FSM-состояния (Finite State Machine)

Для создания поста используется FSM из aiogram:

```
CreatePost:
  waiting_for_text     → Ожидание текста поста
  waiting_for_buttons  → Ожидание кнопок (или пропуск)
  preview              → Предпросмотр и подтверждение
  select_channel       → Выбор канала для публикации
```

## Формат кнопок

Пользователь вводит кнопки в текстовом формате:
```
Текст кнопки 1 - https://example.com
Текст кнопки 2 - https://example2.com
---
Текст кнопки 3 - https://example3.com
```

- Каждая строка = одна кнопка (текст + URL через ` - `)
- Разделитель `---` = новый ряд кнопок
