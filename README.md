# Telegram Poster Bot

Бот для создания и публикации постов в Telegram-каналы. Поддерживает работу с несколькими пользователями — у каждого свои каналы и посты.

## Возможности

- Подключение Telegram-каналов (через пересылку сообщения или @username)
- Создание постов с HTML-форматированием
- Inline URL-кнопки под постами (несколько рядов)
- Предпросмотр поста перед публикацией
- Редактирование текста и кнопок до публикации
- Публикация в выбранный канал
- Хранение постов — повторная публикация из списка
- Изоляция данных между пользователями

## Стек

- Python 3.11+
- aiogram 3.x
- SQLite (aiosqlite)
- Railway.com для деплоя

## Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd telegram-poster-bot

# 2. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — указать BOT_TOKEN

# 5. Запустить бота
python -m bot
```

### Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|-----------|-------------|-------------|----------|
| `BOT_TOKEN` | Да | — | Токен бота от @BotFather |
| `DATABASE_PATH` | Нет | `/data/bot.db` | Путь к файлу SQLite |

Для локальной разработки рекомендуется указать `DATABASE_PATH=./bot.db`.

## Деплой на Railway

### 1. Создать проект на Railway

- Подключить GitHub-репозиторий
- Railway автоматически определит Python-проект через `requirements.txt`

### 2. Добавить Volume

- В настройках сервиса: **Add Volume**
- Mount path: `/data`
- Это нужно для персистентного хранения SQLite-базы между деплоями

### 3. Настроить переменные окружения

В разделе **Variables** сервиса добавить:

```
BOT_TOKEN=<токен от @BotFather>
DATABASE_PATH=/data/bot.db
```

### 4. Деплой

Railway автоматически задеплоит при пуше в main. Стартовая команда задана в `railway.toml`:

```toml
[deploy]
startCommand = "python -m bot"
```

## Как пользоваться

1. **Создать бота** через [@BotFather](https://t.me/BotFather), получить токен
2. **Добавить бота** в канал как администратора с правом публикации
3. **Написать боту** `/start`
4. **Подключить канал**: нажать «📢 Мои каналы» → переслать сообщение из канала или отправить `@username`
5. **Создать пост**: нажать «✍️ Создать пост» → ввести текст → добавить кнопки (опционально) → предпросмотр → опубликовать
6. **Повторная публикация**: «📋 Мои посты» → выбрать пост → «📢 Опубликовать»

### Формат кнопок

Каждая кнопка на новой строке в формате `Текст - URL`:

```
Наш сайт - https://example.com
Telegram - https://t.me/channel
---
Подписаться - https://t.me/channel2
```

- `---` — разделитель между рядами кнопок
- URL должен начинаться с `http://` или `https://`
